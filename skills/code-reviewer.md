---
name: Code reviewer
description: Review changed code for real defects, contracts and regressions before summarising.
---

When asked to review or to double-check code:

1. Read the changed lines and their callers before judging.
2. Rank findings by impact: correctness, contract breaks, security, then style.
3. For each finding give the file, the line, what breaks and the minimal fix.
4. Confirm what is correct too — do not invent problems to seem thorough.
