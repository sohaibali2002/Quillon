3. Scanner results

  • npm audit --omit=dev: 6 advisories (3 high, 3 moderate). image-size (high) — DoS infinite loop in JXL/HEIF/ICNS parsers: relevant to file ingestion; the fix is a breaking upgrade, so it is a release blocker for untrusted uploads until scheduled. postcss (high) — build-time parser; not reachable at runtime. uuid (moderate) — buffer API not used by the exceljs call path.
  • semgrep, gitleaks, trivy, syft: not installed in this workspace; CI does not yet run them. Recommended next: pin Semgrep and Gitleaks actions by SHA, add an SBOM job.
  • npm run check:security: 36 passed (28 before). npx tsc --noEmit: exit 0. npm run build: exit 0.

4. Release-blocking criteria used

  • Any cross-tenant read or write reachable from an authenticated session blocks release.
  • Any path where a model or client-supplied id substitutes for server-side authorization blocks release.
  • Arbitrary code or third-party MCP processes with host filesystem access block release in production profiles.
  • High/critical dependency advisories that are reachable from untrusted input block release until patched or mitigated.

5. Remaining gaps (next phases)

  • DNS rebinding: validated DNS answers are not pinned at the socket; network-level egress enforcement is still required (phase 3).
  • MCP execution isolation: stdio servers still run with the host process's privileges; containers or microVMs with per-server identity are phase 3.
  • Cryptography: AES-256-GCM token encryption exists; database and backup encryption at rest, KMS/HSM envelope keys and rotation are phase 4. FIPS 140-3 validation is a module certification, not a property of the algorithm.
  • Authorization granularity: grants are still connector/action scoped, not per-resource; an ABAC/PDP layer with per-tool resource resolvers is phase 2.
  • Audit independence: signed checkpoints and an optional external sink exist; a mandatory, independently administered WORM/SIEM destination is phase 6.
  • Supply chain: SBOM generation, artifact signing and provenance are not yet in CI.

This report records what the code does today and what was executed to prove it. Enterprise readiness, high assurance and government deployment are separate assurance programmes; nothing here is a certification.
